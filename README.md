# Furutori (隹)

Платформа для изучения японского языка на русском.

## Проблема

В рунете нет качественного современного ресурса для изучения японского, где кандзи, слова и грамматика связаны в единую систему.
Существующие сайты устарели, не адаптированы под мобильные устройства и не дают целостной картины языка.

## Целевая аудитория

- Изучающие японский язык (JLPT N5–N1)
- Преподаватели и репетиторы
- Любители аниме, манги и японской культуры

## Основная ценность

Единая экосистема: полная база кандзи, слов и грамматики с переводами на русский язык, умным поиском и системой интервального повторения.

## Стек

Backend: Go 1.22+, Gin, GORM
Frontend: Next.js 15, TypeScript, Tailwind CSS
База данных: PostgreSQL 16
Поиск: Meilisearch
Кеш: Redis
Парсинг: Python 3.10+
Контейнеризация: Docker, Docker Compose
CI/CD: GitHub Actions
